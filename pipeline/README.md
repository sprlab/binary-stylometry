# Binary Stylometry Pipeline

This folder contains the pipeline to process a binary dataset to generate feature files and the RFC Model. This pipeline is built on top of the original Binary Stylomery work from this repository: https://github.com/calaylin/bda


## Installation

Please follow the instructions in the Install.md file to setup the third party tools required for the pipeline.
Ensure that the following folders are present in the pipeline folder after installation:

- bjoern-radare
- neo4j

Downwload the java libs listed in the `Attribution/jars/reqs.txt` file.

## Dataset Structure Requirements
- A complete dataset would contain a train and a test set.
- Both test and train set should be organized in the following directory structure:
 ```dataset_train/author/task```
 ```dataset_test/author/task```
 - Both the sets must be present in the directory ./Attribution/datasets 
- The train and test set should end with the suffix `_train` and `_test` respectively and must have a common prefix before that.
- Each `author/` folder contains multiple `task/` subfolders, each holding:
- A decompiled C++ file (`task_author_decompiled.cpp`)
- A corresponding binary file (`task_author`)

## Config File

- Both train and test set should have a config file that must be present in the relative directory ./Attribution/config. This can be generated by using `pipeline.py --genconf` command.

## How to use

1. Ensure all the installation steps have correctly taken place.
2. Ensure the dataset meets the required structure and includes a configuration file.
3. Run the pipeline using the `end_to_end.sh` driver script. 
4. Example usage:

```bash
   bash end_to_end.sh dataset_prefix  # Exclude "_train" and "_test" from the prefix
```
4. Once processing is complete:
   - Accuracy and classification results will be stored in `./results/`.
   - The trained model will be saved in `Attribution/models/`.
   - Feature files will be stored in `Attribution/arffs/`.

## End-to-End Pipeline Process

The `end_to_end.sh` script executes the following steps using `pipeline.py`, `arff_parse.py` and `acc.py` scripts:

### Training Phase:
1. Disassemble with NDISASM  
2. Disassemble with bjoern-radare  
3. Extract AST using joern-tools
4. Extract CFG using bjoern-radare
5. Consolidate features into ARFF files  
6. Perform information gain based feature selection and train the RFC model  

### Testing Phase:
1. Disassemble with NDISASM  
2. Disassemble with bjoern-radare
3. Extract AST using joern-tools
4. Extract CFG using bjoern-radare
5. Consolidate features into ARFF files  
6. Extract features from ARFF files to match the information gain-selected features from the training phase  

Finally, the extracted test features are evaluated using the trained model to generate accuracy results.
